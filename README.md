# 지방도시 대전 — CITY BRAWL

한국 지방도시의 상징물들이 벌이는 2D 대전 격투 게임. 브라우저에서 바로 돌아갑니다.

## 로스터

| 캐릭터 | 도시 | 특징 | 필살기 |
|---|---|---|---|
| 돌하르방 | 제주 | 체력 120 · 파워형 | 돌 던지기 |
| 하회탈 | 안동 | 체력 96 · 스피드형 | 파안대소 |
| 거북선 | 통영 | 체력 140 · 방어형 | 화포 발사 |
| 상생의 손 | 포항 | 리치 1.35배 | 해맞이 일격 |
| 갈매기 | 부산 | 체력 88 · 최고 속도 | 급강하 |
| 튀김소보로 | 대전 | 균형형 | 소보로 폭격 |

## 조작

- **1P** — `A`/`D` 이동, `W` 점프, `S` 가드, `J` 약공격, `K` 강공격, `L` 필살기
- **2P** — `←`/`→`, `↑`, `↓`, `1`/`2`/`3`
- 선택 화면에서 `T` 로 1인용(CPU) ↔ 2인 대전 전환

## 구조

```
src/game.html     소스. 여기만 고칩니다
index.html        빌드 결과물. 직접 고치지 마세요
tools/build.py    src/game.html → index.html
```

```bash
python3 tools/build.py
```

캐릭터 이미지는 외부 파일이 아니라 Canvas 도형으로 직접 그립니다.
그래서 자세가 상태별로 바뀌고, 에셋 로딩이 없으며, 파일 하나로 완결됩니다.

## 캐릭터 추가하기

`src/game.html` 의 `ROSTER` 배열에 항목을 하나 넣으면 선택 화면에 자동으로 나타납니다.
`head` 는 머리를 그리는 함수, `proj` 는 필살기 투사체를 그리는 함수입니다.
